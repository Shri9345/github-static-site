# Task 6 - Host a Static Website with GitHub Pages

## 🌐 Live Website Link
[Click here to view live](https://shri9345.github.io/github-static-site/)

## 📁 Description
This repository contains a simple static HTML website hosted using GitHub Pages. It includes:
- `index.html` with basic structure
- Optional `style.css` for custom styling

## 🚀 Steps Performed
1. Created `index.html` locally
2. Initialized git and pushed it to a GitHub repo
3. Enabled GitHub Pages from the repo settings
4. Website was published using the `main` branch and root directory

- Git & GitHub
- GitHub Pages
- HTML
- CSS
